Email Spam Detection using Machine Learning

Project Overview

This project is designed to classify text messages or emails as Spam or Legitimate using Machine Learning. It helps identify unwanted or suspicious messages and distinguish them from genuine messages.

Features

- Enter a message for prediction.
- Detect whether the message is Spam or Legitimate.
- Simple and user-friendly web interface.
- Machine Learning-based classification.

Technologies Used

- Python
- Machine Learning
- Streamlit
- Pandas
- Scikit-learn

Project Files

- "app.py" – Web application interface and prediction.
- "train_model.py" – Model training script.
- "spam_model.pkl" – Trained machine learning model.
- "spam.csv" – Dataset.
- "requirements.txt" – Project dependencies.

How It Works

1. Enter a message in the text box.
2. Click Check Message.
3. The trained model analyzes the message.
4. The application displays the prediction as Spam or Legitimate.
